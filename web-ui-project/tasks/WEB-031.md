# WEB-031 — Extract shared bootstrap

**Phase:** Phase 3 — Headless backend bootstrap (8–12 days)

Extract initialization shared by desktop, MCP where appropriate, and web:

- rustls provider;
- logging;
- sqlx drivers;
- application paths;
- caches and cancellation state;
- built-in driver registration;
- external driver plugin loading;
- schedulers and shutdown hooks.

Do not require a `tauri::AppHandle` for platform-neutral initialization. Introduce focused runtime interfaces for paths, events, and secrets.

Acceptance:

- Desktop startup remains unchanged externally.
- Unit tests can bootstrap application services without a WebView.
- `web` does not require creating a Tauri window.
