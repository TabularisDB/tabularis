**Phase:** Phase 3 — Headless backend bootstrap (8–12 days)

- Add one-time bootstrap tokens, secure session cookies, origin checking, CSRF protection, body limits, request IDs, and redaction.

- Requests without a valid session fail.
- Cross-origin and replay tests fail safely.
- Tokens do not appear in standard logs.
