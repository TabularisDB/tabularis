# WEB-001 — Generate the API inventory

**Phase:** Phase 0 — Governance and measurable baseline (3–5 days)

- Add a script that extracts literal frontend command names.
- Compare them with Tauri handler registration.
- Inventory dynamic command names separately.
- Classify commands by feature group, event use, filesystem use, and authorization level.
- Produce a machine-readable parity file, for example `web-ui-project/docs/web-ui-parity.json`.

Acceptance:

- All 224 currently referenced command names are classified.
- CI fails if an unclassified direct invocation is introduced.
