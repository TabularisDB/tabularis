# WEB-091 — Deep links and install links

**Phase:** Phase 9 — Browser adaptations and release hardening (12–18 days)

- Define browser install route semantics.
- Preserve plugin confirmation and registry selection.
- Keep desktop deep-link handling unchanged.

## Browser install route contract

- The canonical route is `/install/:slug?version=<version>&registry=<base-url>`.
- `slug` is required and uses the registry plugin ID format: lowercase ASCII letters, digits, and hyphens with a maximum length of 64.
- `version` and `registry` are optional. A selected registry must be an HTTP or HTTPS base URL without credentials, query parameters, or fragments.
- A valid route always opens the existing plugin confirmation modal. Installation starts only after an explicit confirmation and uses the selected registry without changing the configured default registry.
- Cancelled or invalid routes return to `/connections` without installing. Successful installs also replace the route with `/connections` so refreshing cannot repeat the request.
- Native `tabularis://install` parsing, event delivery, cold-start replay, and confirmation remain unchanged.
